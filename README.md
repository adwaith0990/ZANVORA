# 🛍️ ZANVORA — Modern E-commerce Website

**ZANVORA** is a modern, premium-style e-commerce website designed to provide users with a clean, simple, and user-friendly online shopping experience.

The website features a responsive layout, elegant design, product cards, product search, category filters, wishlist interactions, and a shopping bag interface.

## 🌟 Features

* **Modern UI:** Premium design with elegant colors and clean typography.
* **Responsive Design:** Compatible with desktop, tablet, and mobile devices.
* **Product Display:** Products displayed with names, prices, categories, and visual cards.
* **Product Search:** Search for products by name or category.
* **Category Filtering:** Filter products by category.
* **Wishlist:** Save and remove products from the wishlist interface.
* **Shopping Bag:** Add products and view the current item count.
* **Smooth Navigation:** Easy-to-use menus and section links.
* **GitHub Pages Hosting:** Published as a static website.

## 🛠️ Technologies Used

* **HTML5** — Website structure.
* **CSS3** — Styling, responsive layouts, and animations.
* **JavaScript** — Search, filters, wishlist interactions, and shopping bag functionality.
* **GitHub** — Source code management.
* **GitHub Pages** — Website hosting.
